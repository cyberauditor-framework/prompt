# AI Training Center Module

## Scope
This module is additive and isolated under `agentic-prompt-engineering-lab/modules/ai-training/`.

## Structure
- `routes/`: standalone module pages
- `components/`: interactive UI building blocks
- `content/`: lesson data files
- `assets/`: diagrams and icons
- `styles/`: module-scoped styling
- `index.js`: module entry exposing `registerModule()`

## Current phase
Phase 2 scaffold only. Lesson data and interactive functionality are added in later phases.
